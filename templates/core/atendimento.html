DÚVIDAS FREQUENTES

Podemos ajudar?

A reserva deste portal vale para retirar um livro?

Não. Este é um protótipo independente de demonstração. As reservas não são enviadas à biblioteca e não garantem a retirada de exemplares reais.

Como consultar os livros disponíveis?

Acesse o acervo com o filtro de disponibilidade. Os resultados representam apenas o banco local de demonstração.

Preciso criar uma conta para pesquisar?

Não. A consulta ao catálogo é pública. A conta demonstrativa é necessária apenas para solicitar e acompanhar reservas.

Posso cancelar uma solicitação?

Sim. Em Minhas reservas, use o botão de cancelamento enquanto a reserva estiver pendente, confirmada ou pronta para retirada.
